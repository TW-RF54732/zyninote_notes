## 資料與資訊 {#q-data-information}

「資料」與「資訊」有何不同？以「算全班 60 人平均身高」為例說明。

### 詳解 {#q-data-information-solution .fold}

- **資料**：問題要處理的原始內容 → 60 筆身高數值。
- **資訊**：資料經整理、分析後得到、可供參考或決策的有意義結果 → 全班平均身高。

見 [[ch1-intro#data-information|資料與資訊]]。

## 平均身高的演算法 {#q-height-algorithm}

承上題，用虛擬語言寫出演算法，並說明輸入資料最適合用什麼資料結構。

### 詳解 {#q-height-algorithm-solution .fold}

```
STEP 1: sum = 0
STEP 2: LOOP 60 times
          a. INPUT height
          b. sum = sum + height
STEP 3: average = sum / 60
STEP 4: OUTPUT average
STEP 5: STOP
```

60 筆同型態資料 → 用**陣列**。

## 使用者與撰寫者 {#q-user-programmer}

說明應用程式使用者與程式撰寫者的差別。

### 詳解 {#q-user-programmer-solution .fold}

- **應用程式使用者**：操作別人寫好的軟體解決問題。
- **程式撰寫者**：針對問題自己寫程式，難度較高。

## 演算法的定義與特性 {#q-algorithm}

什麼是演算法？有哪五個特性？常見的描述方式有哪兩種？

### 詳解 {#q-algorithm-solution .fold}

演算法是為解決特定問題而規劃的一群指令，依序執行即可完成任務。

五特性：**輸入**（可有可無）、**輸出**（至少一個）、**有限性**、**明確性**、**有效性**。

描述方式：**虛擬語言**、**流程圖**。見 [[ch1-intro#algorithm-criteria|演算法的五個條件]]。

## 用 for 迴圈算 n! {#q-factorial-for}

以 C 語言的 `for` 迴圈計算 $n!$。

### 詳解 {#q-factorial-for-solution .fold}

```c
int n, product = 1;
scanf("%d", &n);
for (int m = 1; m <= n; m++)
    product *= m;
printf("%d! = %d\n", n, product);
```

## 影響執行效率的因素 {#q-efficiency-factors}

列舉三種影響程式執行效率的因素。

### 詳解 {#q-efficiency-factors-solution .fold}

1. **CPU 處理速度**
2. **指令集**：同一程式在 RISC 與 CISC 機器上時間不同
3. **編譯器**：同機器、同指令集，不同編譯器產生的執行檔速度不同

## ASCII 與進制 {#q-ascii-bases}

1. `A` 的 ASCII 碼為 1000001，`B` 為何？
2. 8 位元 ASCII 最多可表示幾種字元？
3. $10101_2$ 轉十、八、十六進制。
4. $21_{10} = 00010101_2$ 的 1 補數與 2 補數。

### 詳解 {#q-ascii-bases-solution .fold}

1. 字母碼連續 → **1000010**
2. $2^8 = $ **256**
3. $16+4+1 = $ **$21_{10}$**；$010\,101 \to$ **$25_8$**；$0001\,0101 \to$ **$15_{16}$**
4. 1 補數：每位反轉 → **11101010**；2 補數：再 +1 → **11101011**

## 同一串位元的四種解讀 {#q-1011}

$1011_2$ 若分別以無正負號、1 補數、2 補數、符號帶大小表示，十進制各是多少？

### 詳解 {#q-1011-solution .fold}

| 表示法 | 計算 | 值 |
|---|---|---|
| 無正負號 | $8+2+1$ | **11** |
| 1 的補數 | 最高位 1 為負；反轉得 0100 = 4 | **−4** |
| 2 的補數 | 反轉 +1 得 0101 = 5 | **−5** |
| 符號帶大小 | 符號 1，大小 011 = 3 | **−3** |

見 [[ch1-intro#integer-representation|整數表示法]]。

## 1 補數與 2 補數比較 {#q-complement-compare}

比較 1 的補數與 2 的補數的優缺點。

### 詳解 {#q-complement-compare-solution .fold}

- 1 的補數：**兩種零**（0000、1111）；算術電路較麻煩、效率較差。
- 2 的補數：**只有一種零**（全 0），運算電路簡單，電腦普遍採用。

## IEEE 754 編碼 {#q-float-encode}

將 $-23.75$ 以 32 位元短浮點表示。

### 詳解 {#q-float-encode-solution .fold}

$23.75 = 10111.11_2 = 1.011111_2\times2^4$

- 符號：**1**
- 指數（課本偏移 $+2^{t-1} = 128$）：$4+128 = 132 = $ **10000100**
- 假數：**01111100000000000000000**

答案：`1 10000100 01111100000000000000000`。見 [[ch1-intro#floating-point|實數表示法]]。

（若用正式 IEEE 754 的偏移 127，指數欄為 10000011。）

## IEEE 754 解碼 {#q-float-decode}

`11000010111011100000000000000000` 是短浮點，對應十進制為何？

### 詳解 {#q-float-decode-solution .fold}

拆欄：`1 | 10000101 | 11011100000000000000000`

- 符號 1 → 負
- 指數 $10000101_2 = 133$，課本偏移 128 → $e = 5$
- 值 $= -1.110111_2\times2^5 = -111011.1_2 = $ **−59.5**

（若用正式偏移 127，$e=6$，值為 −119。）
