## 一維陣列位址 {#q-address-1d}

1. 陣列 $a$ 大小 20，起始 100，每元素 4 bytes，求 $a[20]$ 的位址。
2. $d[200]$ 每元素 2 bytes，$d[10]$ 在 1000，求 $d[100]$。
3. $a[-5:15]$ 起始 1200，每元素 4 bytes，求 $a[10]$。
4. $a[f:t]$ 起始 $\alpha$，每元素 $z$ bytes，求 $a[i]$。

### 詳解 {#q-address-1d-solution .fold}

公式 $\text{Loc}(a[i]) = \alpha + (i-f)z$，見 [[ch2-array#address-1d|一維陣列位址]]。

1. $100 + 20\times4 = $ **180**（注意：大小 20 的陣列合法索引只有 0–19，$a[20]$ 已越界，這裡只是套公式）
2. $1000 + (100-10)\times2 = $ **1180**
3. $1200 + (10-(-5))\times4 = $ **1260**
4. **$\alpha + (i-f)z$**

## 二維位址反推（一） {#q-address-2d-a}

$a[2][3]$ 在 118，$a[2][5]$ 在 122，$a[5][2]$ 在 152，求 $a[1][1]$。

### 詳解 {#q-address-2d-a-solution .fold}

$a[2][5] = 122 < a[5][2] = 152$ → **以列為主**，以 $a[2][3]$ 為基準：

- $a[2][5]$：$118 + (0\cdot n + 2)z = 122 \Rightarrow z = 2$
- $a[5][2]$：$118 + (3n - 1)\times2 = 152 \Rightarrow 6n = 36,\ n = 6$
- $a[1][1] = 118 + ((-1)\times6 + (-2))\times2 = 118 - 16 = $ **102**

## 任意上下界二維位址 {#q-address-2d-bounds}

$a[f_1:t_1][f_2:t_2]$ 起始 $\alpha$、元素大小 $z$，求 $a[i][j]$。

### 詳解 {#q-address-2d-bounds-solution .fold}

$m = t_1-f_1+1$，$n = t_2-f_2+1$。

- 以列為主：**$\alpha + ((i-f_1)n + (j-f_2))z$**
- 以行為主：**$\alpha + ((j-f_2)m + (i-f_1))z$**

見 [[ch2-array#address-2d-bounds|任意上下界的二維陣列]]。

## 下三角矩陣的空間 {#q-lower-triangular}

$a[n][n]$ 為下三角矩陣，用一維陣列 $b[\text{Size}]$ 存，Size 最小為何？

### 詳解 {#q-lower-triangular-solution .fold}

第 1 列 1 個、第 2 列 2 個……第 $n$ 列 $n$ 個：$1+2+\cdots+n = $ **$\dfrac{n(n+1)}{2}$**。

## 二維位址反推（二） {#q-address-2d-b}

$a[1][1]$ 在 100，$a[2][3]$ 在 144，$a[3][2]$ 在 128，求 $a[2][5]$。

### 詳解 {#q-address-2d-b-solution .fold}

$a[3][2] = 128 < a[2][3] = 144$ → **以行為主**，以 $a[1][1]$ 為基準：

- $a[2][3]$：$100 + (2m + 1)z = 144 \Rightarrow 2mz + z = 44$
- $a[3][2]$：$100 + (m + 2)z = 128 \Rightarrow mz + 2z = 28$
- 兩式相減得 $mz - z = 16$，與第二式聯立得 $3z = 12$，$z = 4$，$m = 5$
- $a[2][5] = 100 + (4\times5 + 1)\times4 = $ **184**

## 二維位址反推（三） {#q-address-2d-c}

元素大小 1，$a[2][5]$ 在 2061，$a[5][2]$ 在 2085，求 $a[5][8]$。

### 詳解 {#q-address-2d-c-solution .fold}

$a[2][5] < a[5][2]$ → **以列為主**，以 $a[2][5]$ 為基準：

- $a[5][2]$：$2061 + (3n - 3) = 2085 \Rightarrow n = 9$
- $a[5][8] = 2061 + (3\times9 + 3) = $ **2091**
