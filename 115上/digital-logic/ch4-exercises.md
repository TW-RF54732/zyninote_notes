## 簡化準則 {#q-criteria}

$f(w,x,y,z) = \Sigma(2,6,7,13,15)$ 的兩個表式：

$$
f = w'x'yz' + w'xyz' + w'xyz + wxy'z + wxyz \qquad g = w'yz' + w'xy + wxz
$$

依簡化準則說明 $g$ 較 $f$ 簡化。

### 詳解 {#q-criteria-solution .fold}

字母變數數目 $q$ 與乘積項數目 $p$：$q_f = 20$、$p_f = 5$；$q_g = 3 + 3 + 3 = 9$、$p_g = 3$。

$q_g \le q_f$ 而且 $p_g \le p_f$，所以 $g$ 較 $f$ 簡化。見 [[ch4-simplification#simplification-criteria|簡化準則]]。

## 代數化簡 {#q-algebraic}

1. 化簡 $f(x,y,z) = \Sigma(0,2,3,4,5,7)$
2. 化簡 $f(x,y,z) = \Sigma(0,1,4,5)$

### 詳解 {#q-algebraic-solution .fold}

**第 1 題**：把相鄰的最小項兩兩配對合併（$m_0$ 與 $m_2$、$m_3$ 與 $m_7$、$m_4$ 與 $m_5$）：

$$
\begin{aligned}
f &= (x'y'z' + x'yz') + (x'yz + xyz) + (xy'z' + xy'z) \\
&= x'z'(y' + y) + yz(x' + x) + xy'(z' + z) \\
&= x'z' + yz + xy'
\end{aligned}
$$

另一組配對（$m_0$ 與 $m_4$、$m_2$ 與 $m_3$、$m_5$ 與 $m_7$）得 $y'z' + x'y + xz$，也是最簡式（循環質隱項圖，見 [[ch4-simplification#ex-cyclic|例子：循環質隱項圖]]）。

**第 2 題**：

$$
f = x'y'z' + x'y'z + xy'z' + xy'z = x'y'(z' + z) + xy'(z' + z) = x'y' + xy' = y'
$$

## 兩個變數卡諾圖 {#q-kmap-2}

化簡 $f(x,y) = \Pi(1,2)$。

### 詳解 {#q-kmap-2-solution .fold}

0-格子是 $m_1$、$m_2$，1-格子是 $m_0$、$m_3$，兩者都在對角，不相鄰，無法合併：

$$
f = M_1 M_2 = (x + y')(x' + y) = x'y' + xy
$$

這就是 XNOR：$f = x\odot y$。

## 三個變數卡諾圖 {#q-kmap-3}

化簡 $f(x,y,z) = \Sigma(0,2,4,7)$。

### 詳解 {#q-kmap-3-solution .fold}

| $z$ \ $xy$ | 00 | 01 | 11 | 10 |
|---|---|---|---|---|
| **0** | 1 | 1 | 0 | 1 |
| **1** | 0 | 0 | 1 | 0 |

- {0, 2} 得 $x'z'$（唯一包含 $m_2$）。
- {0, 4} 得 $y'z'$（第一欄與最後一欄相鄰；唯一包含 $m_4$）。
- $m_7$ 孤立，得 $xyz$。

$$
f = x'z' + y'z' + xyz
$$

## 四個變數卡諾圖 {#q-kmap-4}

化簡 $f(w,x,y,z) = \Sigma(1,6,7,9,12,14,15)$。

### 詳解 {#q-kmap-4-solution .fold}

- {6, 7, 14, 15} 得 $xy$。
- {1, 9} 得 $x'y'z$。
- {12, 14} 得 $wxz'$。

$$
f = xy + x'y'z + wxz'
$$

## 卡諾圖化簡程序 {#q-kmap-procedure}

1. 求 $f(w,x,y,z) = \Sigma(2,3,4,5,12,13,14)$ 的最簡式。
2. 化簡 (a) $f_1(x,y,z) = \Sigma(1,3,4,5)$；(b) $f_2(x,y,z) = \Sigma(2,3,6,7)$。
3. 化簡 $f(x,y,z) = \Sigma(0,2,4,5,6)$。

### 詳解 {#q-kmap-procedure-solution .fold}

1. {4, 5, 12, 13} 得 $xy'$；{2, 3} 得 $w'x'y$；{12, 14} 得 $wxz'$。$f = xy' + w'x'y + wxz'$。（詳見 [[ch4-simplification#ex-read-cluster|例子：讀出格子群的乘積項]]。）
2. (a) {1, 3} 得 $x'z$、{4, 5} 得 $xy'$：$f_1 = x'z + xy'$（{1, 5} 的 $y'z$ 是多餘的質隱項）。(b) {2, 3, 6, 7} 四格：$f_2 = y$。
3. 第一列 {0, 2, 6, 4} 得 $z'$；{4, 5} 得 $xy'$：$f = z' + xy'$。

## 最簡式 {#q-minimal}

1. 求 $f(w,x,y,z) = \Sigma(7,8,12,13,15)$ 的最簡式。
2. 求 $f(x,y,z) = \Sigma(1,2,3,4,5,6)$ 的最簡式。

### 詳解 {#q-minimal-solution .fold}

1. 必要質隱項 $wy'z'$（唯一包含 8）、$xyz$（唯一包含 7）；$m_{13}$ 用 $wxy'$ 或 $wxz$：

$$
f = wy'z' + xyz + wxy' \qquad\text{或}\qquad f = wy'z' + xyz + wxz
$$

2. 循環質隱項圖，沒有必要質隱項，有兩組最簡式：

$$
f = xz' + x'y + y'z \qquad\text{或}\qquad f = yz' + xy' + x'z
$$

見 [[ch4-simplification#minimal-sop|求最簡 SOP]]。

## 最簡 POS {#q-minimal-pos}

求 $f(w,x,y,z) = \Sigma(5,6,7,9,10,11,13,14,15)$ 的最簡 POS。

### 詳解 {#q-minimal-pos-solution .fold}

0-格子為 0、1、2、3、4、8、12：

- 第一欄 $wx = 00$ {0, 1, 3, 2}：$w = 0$、$x = 0$ 固定 → $(w + x)$。
- 第一列 $yz = 00$ {0, 4, 12, 8}：$y = 0$、$z = 0$ 固定 → $(y + z)$。

$$
f = (w + x)(y + z)
$$

對照最簡 SOP $f = wz + xz + wy + xy$，POS 簡單得多。見 [[ch4-simplification#minimal-pos|求最簡 POS]]。

## 含不在意項的卡諾圖 {#q-dont-care}

1. 求 $f(w,x,y,z) = \Sigma(1,3,7,8,9,12,13,15) + \Sigma_\phi(4,5,10,11,14)$ 的最簡式。
2. 求 $f(w,x,y,z) = \Pi(1,2,3,4,9)\cdot\Pi_\phi(10,11,12,13,14,15)$ 的最簡式。

### 詳解 {#q-dont-care-solution .fold}

1. 把 $\phi$ 當 1：右半 $w = 1$ 的八格與中間兩列 $z = 1$ 的八格，$f = w + z$。
2. 圈 0-格子（$\phi$ 當 0）：{1, 3, 9, 11} 得 $(x + z')$、{2, 3, 10, 11} 得 $(x + y')$、{4, 12} 得 $(x' + y + z)$：

$$
f = (x + z')(x + y')(x' + y + z)
$$

見 [[ch4-simplification#dont-care|不在意項]]。

## 五個變數卡諾圖 {#q-kmap-5}

1. 求 $f(v,w,x,y,z) = \Sigma(0,3,4,5,11,12,13,15,19,20,21,27,28,29,31)$ 的最簡式。
2. 求 $f(v,w,x,y,z) = \Sigma(0,1,4,5,12,15,16,17,21,25,27,30,31) + \Sigma_\phi(9,11,13,14,20,28,29)$ 的最簡式。（原卷寫成 $f(x,y,z)$，但編號到 31，應為五個變數。）

### 詳解 {#q-kmap-5-solution .fold}

編號 $= 16v + 8w + 4x + 2y + z$；$v = 0$ 圖放 0～15，$v = 1$ 圖放 16～31，兩張圖同位置的格子相鄰。

**第 1 題**：

- $xy'$：{4, 5, 12, 13, 20, 21, 28, 29}
- $x'yz$：{3, 11, 19, 27}
- $v'w'y'z'$：{0, 4}
- $m_{15}$、$m_{31}$：$wyz$ {11, 15, 27, 31} 或 $wxz$ {13, 15, 29, 31}

$$
f = xy' + x'yz + v'w'y'z' + wyz \quad(\text{或把 } wyz \text{ 換成 } wxz)
$$

**第 2 題**：

- $w'y'$：{0, 1, 4, 5, 16, 17, 20, 21}（20 為 $\phi$）
- $wz$：{9, 11, 13, 15, 25, 27, 29, 31}（9、11、13、29 為 $\phi$）
- $wx$：{12, 13, 14, 15, 28, 29, 30, 31}（13、14、28、29 為 $\phi$）

$$
f = w'y' + wz + wx
$$

## 列表法求質隱項 {#q-tabulation}

1. 列出 $f(x,y,z) = \Sigma(0,1,2,4,5,7)$ 的質隱項集合。
2. 列出 $f(w,x,y,z) = \Sigma(2,6,7,8,13) + \Sigma_\phi(0,5,9,12,15)$ 的質隱項集合。

### 詳解 {#q-tabulation-solution .fold}

1. 依指標分組、兩兩合併後，沒打勾的是 $0\text{-}0$、$1\text{-}1$、$\text{-}0\text{-}$，即 $\{x'z',\ xz,\ y'\}$。完整步驟見 [[ch4-simplification#ex-tabulation|例子：列表法求質隱項]]。
2. 不在意項也參與合併，得六個質隱項：

| 合併 | 二進制 $wxyz$ | 質隱項 |
|---|---|---|
| (0,2) | 00-0 | $w'x'z'$ |
| (0,8) | -000 | $x'y'z'$ |
| (2,6) | 0-10 | $w'yz'$ |
| (6,7) | 011- | $w'xy$ |
| (8,9,12,13) | 1-0- | $wy'$ |
| (5,7,13,15) | -1-1 | $xz$ |

## 質隱項表 {#q-pi-chart}

用質隱項表求下列函數的最簡式：

1. $f(x,y,z) = \Sigma(0,1,2,4,5,7)$
2. $f(w,x,y,z) = \Sigma(0,1,2,5,7,8,9,10,15)$
3. $f(w,x,y,z) = \Sigma(2,5,6,8,15) + \Sigma_\phi(0,7,9,12,13)$

### 詳解 {#q-pi-chart-solution .fold}

1. 三個質隱項 $xz$、$x'z'$、$y'$ 都是必要質隱項：$f = y' + x'z' + xz$。
2. 必要質隱項 $x'y'$（唯一含 9）、$x'z'$（唯一含 2、10）、$xyz$（唯一含 15）；剩下 $m_5$ 用 $w'y'z$ 或 $w'xz$：

$$
f = x'y' + x'z' + xyz + w'y'z \quad(\text{或 } w'xz)
$$

3. 以列表法求得六個質隱項（$A = xz$、$B = wy'$、$C = w'xy$、$D = w'yz'$、$E = x'y'z'$、$F = w'x'z'$），表頭只放 2、5、6、8、15（不放不在意項）。$A$ 是必要質隱項（唯一含 5、15）；剩下 2、6、8 用 $D$（2、6）與 $B$（8）最省：

$$
f = xz + wy' + w'yz'
$$

見 [[ch4-simplification#prime-implicant-chart|質隱項表]]。

## Petrick 方法 {#q-petrick}

以 Petrick 法求 $f(w,x,y,z) = \Sigma(2,5,6,8,15) + \Sigma_\phi(0,7,9,12,13)$ 的最簡式。

### 詳解 {#q-petrick-solution .fold}

質隱項 $A = xz$、$B = wy'$、$C = w'xy$、$D = w'yz'$、$E = x'y'z'$、$F = w'x'z'$。每一行（最小項）的質隱項 OR 起來：

| 最小項 | 2 | 5 | 6 | 8 | 15 |
|---|---|---|---|---|---|
| 包含它的質隱項 | $D + F$ | $A$ | $C + D$ | $B + E$ | $A$ |

$$
\begin{aligned}
p &= (D + F)\,A\,(C + D)(B + E)\,A \\
&= A(D + CF)(B + E) \\
&= A(BD + DE + BCF + CEF) \\
&= ABD + ADE + ABCF + ACEF
\end{aligned}
$$

三個質隱項的乘積項有 $ABD$（字母數 $2 + 2 + 3 = 7$）與 $ADE$（$2 + 3 + 3 = 8$），選 $ABD$：

$$
f = A + B + D = xz + wy' + w'yz'
$$

見 [[ch4-simplification#petrick|Petrick 方法]]。

## 探索法 {#q-heuristic}

1. 以探索法求 $f(w,x,y,z) = \Sigma(2,5,6,8,15) + \Sigma_\phi(0,7,9,12,13)$ 的最簡式。
2. 以探索法求 $f(v,w,x,y,z) = \Sigma(4,6,7,10,11,14,18,19,22,26) + \Sigma_\phi(3,5,15,20,21,23,27)$ 的最簡式。

### 詳解 {#q-heuristic-solution .fold}

**第 1 題**：$A = xz$ 是必要質隱項，移除 5、15 行。剩下的表中 $C$、$F$ 被 $D$ 包含、$E$ 被 $B$ 包含，消去後 $B$、$D$ 成為第二必要質隱項：$f = xz + wy' + w'yz'$。詳細步驟見 [[ch4-simplification#ex-heuristic|例子：探索法]]。

**第 2 題**：編號 $= 16v + 8w + 4x + 2y + z$。由列表法得九個質隱項，以及它們包含的（非不在意）最小項：

| 質隱項 | 包含的最小項 |
|---|---|
| $w'x$ | 4, 6, 7, 22 |
| $v'yz$ | 7, 11 |
| $w'yz$ | 7, 19 |
| $x'yz$ | 11, 19 |
| $v'xy$ | 6, 7, 14 |
| $v'wy$ | 10, 11, 14 |
| $wx'y$ | 10, 11, 26 |
| $vw'y$ | 18, 19, 22 |
| $vx'y$ | 18, 19, 26 |

1. **必要質隱項**：只有 $w'x$ 包含 4，標 \*，移除 4、6、7、22 行。
2. **消去被包含列**：$v'yz$（11）被 $v'wy$ 包含；$v'xy$（14）被 $v'wy$ 包含；$w'yz$（19）與 $vw'y$（18、19）被 $vx'y$（18、19、26）包含。
3. **第二必要質隱項**：剩下的表中只有 $v'wy$ 含 14、只有 $vx'y$ 含 18，兩者標 \*\*，它們已包含 10、11、14、18、19、26 所有行。

$$
f = w'x + v'wy + vx'y
$$

## 變數引入圖 {#q-vem}

1. 以變數引入圖法求下圖的最簡式（三變數，欄 $xy$、列 $z$）：

| $z$ \ $xy$ | 00 | 01 | 11 | 10 |
|---|---|---|---|---|
| **0** | $B'$ | 0 | 0 | $A$ |
| **1** | 1 | $B$ | $\phi$ | 1 |

2. 用三個變數 $(w,x,y)$ 的卡諾圖，求 $f(w,x,y,z) = w'x'y + w'xy + w'xy'z + wxyz + (wx'y)$ 的最簡式，其中 $(wx'y)$ 為不在意項。

### 詳解 {#q-vem-solution .fold}

**第 1 題**：

1. 外部變數全設 0：{1, 5}（7 為 $\phi$）得 $y'z$。
2. $A$：$m_4$ 當 1、原 1-格子當 $\phi$，{4, 5} 得 $xy'$ → $Axy'$。
3. $B$：$m_3$ 當 1，{1, 3, 5, 7} 得 $z$ → $Bz$。
4. $B'$：$m_0$ 當 1，{0, 1} 得 $x'y'$ → $B'x'y'$。

$$
f = y'z + Axy' + Bz + B'x'y'
$$

**第 2 題**：先求每個 $(w,x,y)$ 組合下的餘式，填入三變數圖（$z$ 為引入變數）：

| $wxy$ | 000 | 001 | 010 | 011 | 100 | 101 | 110 | 111 |
|---|---|---|---|---|---|---|---|---|
| 格子 | $m_0$ | $m_1$ | $m_2$ | $m_3$ | $m_4$ | $m_5$ | $m_6$ | $m_7$ |
| 填入 | 0 | 1 | $z$ | 1 | 0 | $\phi$ | 0 | $z$ |

1. $z$ 設 0：{1, 3}（5 為 $\phi$）得 $w'y$。
2. $z$：$m_2$、$m_7$ 當 1，{1, 3, 5} 當 $\phi$：{2, 3} 得 $w'x$、{1, 3, 5, 7} 得 $y$ → $z(w'x + y)$。

$$
f = w'y + w'xz + yz
$$

見 [[ch4-simplification#vem|變數引入圖]]。

## 餘式 {#q-residue}

1. 求 $f(u,v,w,x,y,z) = uvw + x'y'z'$ 在 $ux'z$ 與 $vy'z'$ 下的餘式。
2. 求 $f(w,x,y,z) = w'x'y + w'xy + w'xy'z + wxyz + (wx'y)$ 在 $(w,x,y)$ 所有 8 種組合下的餘式，其中 $(wx'y)$ 為不在意項。
3. 用餘式圖法求上一題在 $(w,x,y)$ 下所有組合的餘式。

### 詳解 {#q-residue-solution .fold}

**第 1 題**：非補數的變數設 1、補數形式的設 0。

- $ux'z$：$u = 1, x = 0, z = 1$ → $f = vw + 1\cdot y'\cdot 0 = vw$
- $vy'z'$：$v = 1, y = 0, z = 0$ → $f = uw + x'\cdot 1\cdot 1 = uw + x'$

**第 2 題**：逐一代入 $(w,x,y)$，看剩下關於 $z$ 的函數：

| $wxy$ | 000 | 001 | 010 | 011 | 100 | 101 | 110 | 111 |
|---|---|---|---|---|---|---|---|---|
| 餘式 | 0 | 1 | $z$ | 1 | 0 | $\phi$ | 0 | $z$ |

例如 $wxy = 010$：只有 $w'xy'z$ 留下，等於 $z$；$wxy = 101$：只有不在意項 $wx'y$，為 $\phi$。

**第 3 題**：最小項 2、3、5、6、7、15 加圈，不在意項 10、11 加星號，餘式圖每一行是 $wxy$ 的一個組合，兩格分別是 $z = 0$、$z = 1$：

- 000（0, 1）：都沒圈 → 0
- 001（②, ③）：全圈 → 1
- 010（4, ⑤）：只有 $z = 1$ 圈 → $z$
- 011（⑥, ⑦）：全圈 → 1
- 100（8, 9）：→ 0
- 101（10\*, 11\*）：全星號 → $\phi$
- 110（12, 13）：→ 0
- 111（14, ⑮）：只有 $z = 1$ 圈 → $z$

結果與第 2 題相同。見 [[ch4-simplification#residue-map|餘式圖]]。
